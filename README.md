## 📌 Project Overview
This project applies predictive data analytics and machine learning to analyze customer churn risk, evaluate revenue attrition drivers, and deliver actionable business retention strategies.

## 🔗 Dataset Link
- **Source:** Kaggle Telco Customer Retention Dataset
- **Access URL:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## 🛠️ Tech Stack
- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn)
- Random Forest Classifier
- Jupyter Notebook

## 📊 Core Insights
- Customers with >3 support calls have a churn probability over 60%.
- Month-to-month contracts represent the highest attrition cohort.
- Support frequency and contract duration are the strongest predictors of churn.
